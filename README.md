# 🌸 Messa Studio

**Arte floral que transforma espacios**

Un sitio web elegante y profesional para Messa Studio, especialistas en diseño floral para eventos, restaurantes y espacios corporativos.

## ✨ Características

- 🎨 **Diseño Minimalista** - Interfaz limpia y elegante
- 📱 **100% Responsive** - Optimizado para todos los dispositivos
- ⚡ **Performance Optimizada** - Carga rápida y eficiente
- 🔒 **Seguridad Avanzada** - Headers de seguridad implementados
- 🌐 **SEO Optimizado** - Meta tags y estructura semántica
- 🎥 **Video Hero** - Experiencia visual inmersiva

## 🚀 Tecnologías

- **Framework**: [Astro](https://astro.build/) v5.12.6
- **Lenguaje**: TypeScript
- **Estilos**: CSS Variables + Flexbox/Grid
- **Fuentes**: [Satoshi](https://www.fontshare.com/fonts/satoshi)
- **Deploy**: Vercel

## 📁 Estructura del Proyecto

```
messa-studio/
├── src/
│   ├── components/     # Componentes reutilizables
│   ├── layouts/        # Layouts de página
│   └── pages/          # Páginas del sitio
├── public/
│   ├── images/         # Imágenes y logos
│   └── video/          # Video hero
└── astro.config.mjs    # Configuración de Astro
```

## 🛠️ Instalación

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/njofrey/messa.git
   cd messa
   ```

2. **Instalar dependencias**
   ```bash
   npm install
   ```

3. **Ejecutar en desarrollo**
   ```bash
   npm run dev
   ```

4. **Construir para producción**
   ```bash
   npm run build
   ```

## 📱 Secciones del Sitio

- **Hero** - Video inmersivo con mensaje principal
- **Proyectos** - Portfolio de trabajos realizados
- **Sobre Messa** - Filosofía y enfoque del estudio
- **Contacto** - WhatsApp e Instagram directos

## 🎯 Funcionalidades

- **Navegación Suave** - Scroll suave entre secciones
- **Animaciones** - Efectos fade-in con Intersection Observer
- **Menú Móvil** - Navegación hamburguesa responsive
- **Enlaces de Contacto** - WhatsApp e Instagram integrados
- **Lazy Loading** - Carga optimizada de imágenes

## 🌟 Características Técnicas

- **CSS Variables** - Sistema de colores y tipografía consistente
- **Grid Layout** - Diseño moderno y flexible
- **Media Queries** - Breakpoints optimizados para móvil
- **Performance** - Optimizaciones de carga y renderizado
- **Accesibilidad** - Alt text y navegación por teclado
